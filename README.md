## 概述
本工具是一款纯前端实现（无需后端服务）的数学计算器，基于 HTML、CSS 和 JavaScript 开发。它专为日常快速数学计算设计，界面友好且支持一键切换中英文语言，方便中英双语使用者操作。

工具核心支持基础算术运算及常用数学功能，无需安装，可直接在任意现代浏览器中运行。

## 前置条件
无需复杂的配置或依赖项！你仅需准备：
- 一款现代网页浏览器（Chrome、Firefox、Edge、Safari 等）
- 本地保存文件后无需联网（可离线运行）

## 使用方法
### 1. 运行工具
- 将所有项目文件（index.html）下载到本地电脑
- 双击 `index.html` 文件，直接在浏览器中打开
- 或将文件部署到网页服务器（如 Nginx、Apache），通过 URL 访问

### 2. 切换语言
- 找到界面右上角的「语言切换」按钮
- 点击按钮可在以下语言间切换：
  - 🇨🇳 中文（简体中文）
  - 🇬🇧 英语（美式英语）
- 所有界面文本（按钮、标签、提示语）会即时更新

### 3. 执行计算
- 使用屏幕上的数字按钮（0-9）和运算按钮（+、-、×、÷、=）
- 点击「AC」清空所有输入内容
- 点击「←」删除最后一个输入字符
- 在顶部显示区域查看计算结果

## 核心特性
- 🌐 **双语支持**：界面可无缝切换中英文
- 🧮 **基础算术**：支持加、减、乘、除运算
- 🚀 **轻量高效**：纯前端实现（无外部库/框架依赖）
- 💻 **离线使用**：本地下载后无需联网即可运行
- 🎨 **响应式设计**：适配桌面端、平板、手机等不同屏幕
- ⚠️ **错误处理**：对无效操作（如除零运算）给出友好提示
